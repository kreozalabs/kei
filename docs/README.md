# Kei

Kei is a software that is initially developed to make calendar application customizable, helpful and open-source.

It is not meant to either compete or replace other tools, such as Google Calendar, Todoist, etc. Instead main focus is on developing a piece of software that serves user!

## About Docs

This directory is meant for developers to understand the whole architecture.

## Design

- It is **Event-Driven**. User data that is stored as events. Learn more in [Docs on Event-Driven Architecture](./design/event-driven-arch.md)
- It is **Plugin-Driven**. Core app is minimal and just enough to work. Components make the difference! Learn more in [Docs on Plugin-Driven Architecture](./design/plugin-driven-arch.md)
